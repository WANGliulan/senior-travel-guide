# 智游康行 · 岁旅相伴 — 微信小程序源码

面向老年人的旅游规划智能体微信小程序（大模型与智能体应用赛道）。
基于原 Web 版 Tour-AI（Next.js）按《小程序前后端设计方案》改写的可运行版本：
**规则引擎前置过滤 + 知识库 + 大模型生成 + 多轮迭代**的混合智能体架构。

```
项目结构
├── project.config.json        微信开发者工具项目配置（appid 为 touristappid，可直接导入）
├── miniprogram/               小程序前端（原生 WXML + WXSS + JS，全局适老化 UI）
│   ├── app.js / app.json / app.wxss / sitemap.json / config.js
│   ├── utils/                 api 封装（云函数优先，失败自动降级本地模拟）、本地存储、格式化、模拟数据
│   └── pages/                 7 个页面：
│       ├── index/             首页：地区板块大卡片选择目的地
│       ├── form/              老年出行信息表单（全单选/下拉，减少打字）
│       ├── generating/        行程生成中（进度化提示）
│       ├── itinerary/         行程结果：分天行程 + 风险评估 + 出行贴士 + 快捷调整 + 保存/复制/分享图
│       ├── chat/              智能体多轮对话（自然语言调整，身体约束持续生效）
│       ├── history/           我的方案（历史查看/删除）
│       └── settings/          适老化设置（字体大小、高对比度、数据管理）
└── cloudfunctions/            微信云开发后端（Node.js 云函数）
    ├── login/                 获取微信 openid（替代原邮箱注册登录）
    ├── cities/                地区板块与城市列表
    ├── attractions/           规则引擎前置过滤候选景点
    ├── itinerary/             生成老年专属行程（规则引擎→知识库→大模型→风险评估→出行贴士）
    ├── dialogue/              多轮对话调整行程（大模型优先，关键词规则兜底）
    ├── adjust/                快捷调整按钮（纯规则引擎，确定性修改）
    └── plan/                  方案保存/列表/详情/删除（云数据库）
```

## 一、直接运行（推荐先用这步）

1. 打开**微信开发者工具** → 导入项目 → 选择本目录；
2. AppID 选择「测试号」或使用自己的 AppID（project.config.json 已配置 `touristappid`，可直接以游客模式打开）；
3. 无需任何配置即可运行：`config.js` 中 `CLOUD_ENV` 默认为空，前端自动进入**本地模拟模式**，全部页面与业务流程（生成行程、调整、对话、保存、分享）均可完整演示。

> 本地模拟模式的数据结构与云函数完全一致，仅用于界面与流程演示；接入真实后端后切换为云函数数据。

## 二、接入真实后端（云开发）

1. 在微信开发者工具中点击「云开发」开通环境，记下**环境 ID**；
2. 把环境 ID 填入 `miniprogram/config.js` 的 `CLOUD_ENV`；
3. 在 `cloudfunctions` 目录下，对 **login / cities / attractions / itinerary / dialogue / adjust / plan** 每个文件夹
   右键 →「上传并部署：云端安装依赖」；
4. 首次运行会自动调用 `login` 云函数写入用户标识；云数据库会自动创建 `users`、`plans` 集合。

### 大模型配置（可选，默认有兜底）

在云函数控制台为 `itinerary`、`dialogue` 两个函数配置环境变量：

| 环境变量 | 说明 | 默认值 |
|---|---|---|
| `LLM_API_KEY` | 大模型 API Key（OpenAI 兼容接口，如通义千问 DashScope） | 空（未配置时自动走规则引擎模板兜底，功能依然完整） |
| `LLM_BASE_URL` | 接口地址 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| `LLM_MODEL` | 模型名 | `qwen-max` |

配置后，行程生成与对话将由大模型智能体完成；生成失败或未配置时自动回退到规则引擎兜底方案，保证演示不中断（这正是"规则兜底、大模型出内容"的混合架构设计）。

## 三、与原 Web 版（Next.js Tour-AI）的对应关系

| 原功能 | 小程序实现 |
|---|---|
| 邮箱注册/登录（NextAuth + Prisma） | 微信 openid 登录（`login` 云函数），身体信息本地复用 |
| AI 行程生成（千问 API + 高德图片） | `itinerary` 云函数：规则引擎过滤 → 知识库 → 大模型 → 风险评估 → 出行贴士 |
| AI 助手流式对话 | `chat` 页 + `dialogue` 云函数（非流式，多轮约束持续生效） |
| 行程保存/管理 | `plan` 云函数（云数据库）+ 历史页 |
| 兴趣/天数参数化生成 | 适老信息表单（身体参数为硬约束） |
| 小红书笔记解析、旅行日记、定价/联系页 | 与适老定位及设计文档不符，未移植（如需可在后续版本扩展） |

## 四、数据与知识库说明

- `cloudfunctions/_shared/data.js`：示范城市景点知识库（体力等级/无障碍/人流量/类型/步行量/休息点/就近医疗）+ 老年出行科普知识库（饮食忌口、天气穿衣、随身物品、休息建议）。
- 规则引擎（`rulesEngine.js`）：按老人身体参数（行动能力、慢病、无障碍需求、单日步行上限）前置过滤高体力、多台阶、无人流适配、无无障碍配套的景点，并依兴趣偏好打分排序。
- 升级路径：可将景点库替换为腾讯云向量数据库 + embedding 检索，字段结构保持不变。

## 五、常见问题

- **导入后提示找不到页面？** 请确认导入的是本目录（含 project.config.json），并已重新编译。
- **tabBar 无图标？** 微信 tabBar 的 iconPath 为可选项，本项目以文字为主，适配长辈大图标浏览；如需图标可在对应 page 目录放置 png 并配置。
- **云函数部署失败？** 每个云函数目录都是自包含的（含公共模块副本），确保以「云端安装依赖」方式上传。
